# MYS CODE

Windows uchun MYS CODE ilovasi.

**[MYS-CODE-Setup-1.0.0.exe — yuklab olish](https://github.com/MYS707team/MYS_CODE/releases/download/v1.0.0/MYS-CODE-Setup-1.0.0.exe)**

## O‘rnatish

1. Yuqoridagi setup EXE faylini yuklab oling.
2. Faylni ochib, o‘rnatishni tugating.
3. MYS CODE ilovasini oching va hisobingizga kiring.

Python, mahalliy xizmat va Chrome/Edge extensioni installer ichida. Alohida ZIP
yoki Python yuklab olish kerak emas.

## Brauzer extensionini ulash

Bir marta sozlang:

1. Ilovada **Settings → Browser extension → Open extension folder** ni oching.
2. Chrome’da `chrome://extensions`, Edge’da `edge://extensions` sahifasini oching.
3. **Developer mode** ni yoqing, **Load unpacked** ni bosing va ochilgan extension
   papkasini tanlang. Desktop’da extension ID’ni tasdiqlang va AI sahifasini yangilang.

## Talablar

Windows 10/11, 64 bit; Microsoft Edge WebView2 Runtime; internet ulanishi.

Relizdan yuklab olinadigan fayl — faqat tayyor setup EXE.
